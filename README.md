# Credit_Card_Churn_SQL_Analysis

 ## Project Overview

This project focuses on analyzing customer behavior in a credit card dataset to better understand churn (customer attrition) patterns.

The main goal is to:

Identify high-risk customers
Analyze behavioral differences between churned and existing users
Build simple analytical and scoring models using SQL

## Objectives
Analyze customer activity, transactions, and engagement
Segment customers based on different behavioral metrics
Calculate churn rates across multiple dimensions
Detect high-risk customer groups
Build a simple churn scoring model
Create a loyalty index and evaluate its effectiveness

## Key Analyses
1. Customer Segmentation
Income-based analysis
Age group churn comparison
Card category & gender distribution
2. Behavioral Analysis
Transaction amount & count patterns
Inactivity and contact frequency impact
Utilization ratio insights
3. Churn Analysis
Churn rate by:
Age groups
Income categories
Marital status
Customer activity levels
4. Advanced SQL Techniques
Window functions (RANK, NTILE, LAG)
Running totals & cumulative percentages
Percentile-based segmentation (Top 10%, Bottom 10%)
Cohort analysis
